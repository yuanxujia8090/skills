# skills

袁旭佳的 agent 技能集合。

## 技能

- [yxj-illustrations](yxj-illustrations/)：云端生图版圆点封面与分享卡（OpenAI 形状图片接口，gpt-image-2），要人时用设定卡做参考图锁身份；每次出图计费。
- [yxj-illustrations-comfyui](yxj-illustrations-comfyui/)：通过本机 ComfyUI 生成圆点封面与分享卡，支持参考图、中文后期排字和机检。

## 安装

克隆后，将单个技能目录复制到所用 agent 的技能目录；也可让 agent 直接读取该目录的 `SKILL.md`。各技能的环境前提、依赖与限制见各自 README。

本仓库不包含模型权重、字体文件、凭据或生成结果。不自动启动后端，不自动安装模型。
