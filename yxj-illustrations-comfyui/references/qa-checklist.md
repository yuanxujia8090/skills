# 质检清单

- [ ] 画幅对：封面/分享卡按平台比例，内容图 1536×1024（3:2）；留白够，一张图一个意思
- [ ] 风格2 手绘带标注：暖白纸纹、细墨线、轻水彩平涂；只有墨黑/朱红/藏蓝三色 + 纸底
- [ ] 不是彩色铅笔排线、不是光滑二次元、不是 3D 或高光质感
- [ ] 帽上是朱红五角星 `#E8552D`（不是红圆点、不是黄星、不是正红）
- [ ] 羽绒服是藏蓝 `#1F3A5F`（不是浅蓝）
- [ ] 圆点在做核心动作，不是旁观贴纸
- [ ] 圆点**最多出现一次**（没有多视图、分镜多人物、角色设定卡排版）；**完全没有人也合格**
- [ ] 圆点是小的（全身约 20–25% 图高、远景全身），主要物件比人大
- [ ] 主物件 3–5 个，没有密集节点网
- [ ] 线条细、略不规则，不是粗描边/矢量网格
- [ ] 中文批注少而准，无严重错字（尤其勿「专注码代码」）
- [ ] 无 PPT/架构图标题条
- [ ] 无日本国旗式白底红圆
- [ ] 未漂移成小黑或其他 IP

## 本地 ComfyUI 版加项

- [ ] 批注只出现在 `--labels` 白名单内，无多余乱码、签名、角落标题
- [ ] 没有把设定卡版式带进来（多视图排版、正面站桩、色卡）
- [ ] 不是多个圆点重复出现（参考图的多视图容易诱发）
- [ ] 文字或身份不过关 → 换 seed 整张重出，不局部修字；同一张连续 3 次不过 → 改用云端 `yxj-illustrations`
- [ ] 不能看图的会话：交付写明「未做人工目视」
- [ ] `verify.py` 机检：文字块 0、人脸 1（>0 或 >1 见 SKILL.md 坑⑪）
- [ ] 画面里**没有模型自己写的字**（角落标题、签名、乱码批注）——机检可能漏中文小字，仍需人眼看
- [ ] 批注 **4–8 处**（基准 5 处），每个主要结构至少一处
- [ ] 批注环绕分布，没有全挤在左侧/右侧/角上成一列
- [ ] 批注距笔画 **8–30px**（`add_labels.py` 输出里的 `gap_px`），读者一眼看出标的是哪个东西
- [ ] 叠字只叠了一遍，颜色在朱红/藏蓝/黑范围内
- [ ] 叠字没压住圆点的脸和核心动作，没贴边（留 ≥4%）
- [ ] 批注文案与正文一致，没有错别字（叠字是人写的，必须自己核一遍）
