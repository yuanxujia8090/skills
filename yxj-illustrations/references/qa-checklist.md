# 质检清单

## 结构与人物

- [ ] 一张图只讲一个核心意思，结构类型只选了一种
- [ ] 主物件 3–5 个，物件是主体，占画面约 40–60%
- [ ] **人物 ≤ 1 个**：没有多视图、没有分镜多人物、没有左右对比各站一个、没有设定卡排版
- [ ] **人物大小约 20–25% 图高**：全身远景，不是半身、不是大头、不是近景
- [ ] **不出现也合格**：结构自己说得清时画里没有人，是正确结果，不要为了「有 IP」硬塞
- [ ] 有圆点时他在做核心动作，不是站在角落旁观

## 线条与布局

- [ ] 风格2 手绘带标注：暖白纸纹、细墨线、轻水彩平涂；只有墨黑/朱红/藏蓝三色 + 纸底
- [ ] 不是彩色铅笔排线、不是光滑二次元、不是 3D 或高光质感
- [ ] 线条细、略带抖动；没有粗描边、矢量直边、规则网格、刻度尺辅助线
- [ ] 阴影只用同色低透明水彩平涂，没有铅笔排线堆灰、渐变、光影
- [ ] 留白 ≥35%，有一块安静区域给批注
- [ ] 一条主流向（左→右或上→下），没有多层箭头
- [ ] 主体不居中排成海报

## 身份

- [ ] 帽上是朱红五角星 `#E8552D`（不是红圆点、不是黄星、不是正红）
- [ ] 羽绒服是深蓝（不是浅蓝）
- [ ] 没有漂移成小黑或其他 IP，不是 AI 帅哥脸

## 文字

- [ ] 中文批注 4–8 处（基准 5 处），每处 2–6 字
- [ ] 批注贴着对应物件，环绕主体分布，没有全挤一侧或角上成一列
- [ ] 无严重错字（尤其勿「专注码代码」）
- [ ] 无 PPT/架构图标题条，图上没有结构类型名

## 失败信号（命中即重画，别硬交付）

- 第一眼像教程页 / 流程图 / 课程课件
- 元素太多、箭头太多、节点太多
- 人是主体、物件是背景
- 一个人变成几个人，或一张图里出现设定卡三视图
- 白底红圆（像日本国旗）
