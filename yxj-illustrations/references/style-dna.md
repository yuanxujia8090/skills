# 风格 DNA（圆点 · 可用版 V1 · 风格2 手绘带标注）

> 2026-11-13 改版：画法从「彩色素描」统一到 **风格2 手绘带标注**，与 `yxj-content-workflow-v8`
> 的封面口径合并为同一套。角色形象（可用版 V1）不变。
> 视觉真源：`obsidian-wiki/自媒体/00 定位/生图风格2：手绘带标注.md`

## 一句话

手绘马克笔＋水彩、暖白纸纹、细墨线、只用三色、大量留白、带手写短标签。

像「圆点」在一张暖白纸上用马克笔画出来的解释草图，不是商业插画，也不是二次元海报。

## 必带英文锚点（每张提示词逐字复制，不缩写）

```text
hand-drawn marker-and-watercolor editorial illustration on warm off-white paper (#F5F0E6)
with subtle paper grain. Thin imperfect ink linework (#1A1A1A), light flat watercolor fill.
Only three accent colors: ink black, burnt orange (#E8552D), navy (#1F3A5F).
Flat 2D storybook-infographic look, playful but tidy, generous negative space,
hand-lettered labels that stay perfectly legible.
No 3D, no photorealism, no glossy highlights, no stock clip-art look.
```

只写 `hand-drawn line` 或 `sketch line art` 不够，锚点必须完整。

## 画面构成（2026-11-06 定，优先于其它描述）

一句话：**物件和结构是主体，圆点是场景里干活的那个小角色，而且不一定出场。**

| 规则 | 要求 | 为什么 |
| --- | --- | --- |
| 人物 0 或 1 次 | 一张图最多一个圆点；多状态（之前/之后、卡住/跑起来）用**物件状态**表达，不重复画人 | 多个人物会抢走结构表达，读者先看人再看意思 |
| 人物要小 | 全身约 **20–25%** 图高，远景全身；不画半身、不画大头、不画多视图 | 配图是解释结构，不是人物海报 |
| 可以不出现 | 结构自己就能说明白时（漏斗、闸门、秤、抽屉分层、一条路线），**不画人** | 人缺席时图意仍成立，就不该硬塞人 |
| 物件更大 | 机器、抽屉、柜子、漏斗、纸带、闸门等主要物件都比人大，占画面 40–60% | 让眼睛先落在「这东西怎么运转」 |
| 单一结构 | 一个核心动作 + 3–5 个主物件；不要密集节点网、多层箭头、均匀网格 | 元素一多立刻变成 PPT |

结构类型从 `references/composition-patterns.md` 里选一种，不要混。

## 线条

- 细墨线、略微不抖齐、手绘感；线条密度低，别把每个结构都勾满。
- 不要粗描边、不要均匀矢量线、不要规则网格和刻度尺式辅助线。
- 阴影用**同色低透明水彩平涂**，不用铅笔排线堆灰、不用渐变光、不用投影。

## 布局

- 留白 ≥35%，最好留一整块安静区域给标签。
- 主体偏一侧或偏中下，不要居中排版成海报。
- 只有一条主流向（左→右，或上→下），读者能顺着入口走到出口。
- 圆点若出场，放在主流动线上承担动作，不要缩进角落当装饰。

## 必须

- **画幅**：封面按平台安全区（公众号首图 ≈2.35:1，分享方图 1:1）；解释型内容图 1536×1024（3:2）。不做满版 16:9 通用图。
- 暖白纸底 `#F5F0E6` + 轻微纸纹；不要复杂场景背景、渐变天空、赛博 UI。
- **只有三种颜色**：墨黑 `#1A1A1A`、朱红 `#E8552D`、藏蓝 `#1F3A5F`。水彩只用这三色的低透明度。
- 平面 2D 故事书信息图感，活泼但整齐。
- 中文手写短标签：一张图 **4–8 处**（基准 5 处），每处 2–6 个字，贴着对应物件环绕主体分布，必须清楚可读。
- 一张图只讲一个核心意思。
- 圆点若出现，必须承担核心动作；只出现一次、只占 20–25% 图高。

## 颜色映射（重要，别生成第四种红）

旧彩色素描有五色，风格2 只有三色。按下面映射，不要凭空加色：

| 用途 | 旧 | 新 |
| --- | --- | --- |
| 线稿、帽子、裤子、主要文字 | 黑 | 墨黑 `#1A1A1A` |
| 羽绒服 | 深蓝 | 藏蓝 `#1F3A5F`（**不要改浅蓝**） |
| 帽上五角星、机器人脸星、重点批注 | 正红 | 朱红 `#E8552D`（**不要再用正红 `#FF0000`**） |
| 流程箭头、路径 | 橙 | 朱红 `#E8552D` |
| 第二层解释 | 浅蓝 | **取消**；需要区分就用线条粗细与位置，不加色 |

## 绝对不要

- 帽标用红圆点（易像日本国旗联想）。
- 标准 AI 帅哥脸、完美光影、高饱和二次元。
- PPT 信息图、正式流程图、复杂架构图。
- 半身近景、大头像、角色设定卡三视图、同一张图里多个圆点。
- 幼稚卖萌、儿童插画、精致商业扁平插画。
- 3D、写实照片质感、高光、剪贴画感。
- 左上角写「流程图 / 架构图 / 常见坑」等类型标题。
- 照搬小黑外形或主题。
