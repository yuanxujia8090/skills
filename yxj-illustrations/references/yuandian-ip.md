# 圆点 IP（可用版 V1）

## 角色定义

圆点是「圆点 Agent 栈」封面与分享卡的固定视觉 IP，来自真人简化形象；画法用风格2 手绘带标注（马克笔＋水彩＋纸纹）。

**出场原则（2026-11-06 定）：画面以物件和结构为主体，所以圆点一张图最多出现一次，也不是每张必出。**

- 结构自己就能说明白（漏斗、闸门、秤、抽屉分层、一条路线）→ **不画人**，只画物件。
- 需要一个手去推、拉、盖、搬、示范判断 → 画一个圆点，**全身远景，约 20–25% 图高**。
- 他一旦出场，就必须承担核心动作；只是站在旁边看，就删掉他，或者改 prompt 让他动手。

可选搭档：圆点机器人（圆形小白机器人，脸屏一枚红色五角星）。机器人不能用来凑人数。

## 外形（锁定）

- 东亚男性，短发，平静专注，五官简化，不卖萌。
- 黑棒球帽，正面一枚**朱红五角星** `#E8552D`（唯一帽标）。
- **藏蓝**绗缝羽绒服 `#1F3A5F`，黑内搭，黑裤，白鞋（鞋可简化）。
- 风格2：细墨线 + 同色低透明水彩平涂；不用彩色铅笔排线。身体比例接近常人简化（约 1:4），不要大头娃娃。
- 在正文配图里画成**小的全身远景（约 20–25% 图高）**，主要物件明显比他大；不要半身、不要近景、不要大头贴。
- 无痣（可用版 V1 无嘴角黑点）。

## 性格

- 冷静、动手、实测说话。
- 冷幽默，不卖萌。
- 像邻座认真写代码的人。

## 常见职责（圆点要做的事）

- 敲键盘实测、指便签记录、拿放大镜查问题。
- 卡住断点、拉线、分拣、搭桥、盖「通过/重来」章。
- 对比两个方案、推工具小车、举警示牌看坑。

圆点机器人可：探头偷看、冒汗、递工具、举红星小旗（旗面勿做成白底红圆国旗样式；用红星或便签）。

## 禁止

- 不要红圆点帽标；不要黄星（应用红星）。
- 不要浅蓝色羽绒服。
- 不要把圆点画成二次元帅哥 / 新海诚海报脸。
- 不要只站角落旁观。
- 不要同一张图里出现两个及以上圆点（包括分镜每格一个、设定卡三视图、左右对比各站一个）。
- 不要画成人物海报：半身、大头、脸占画面一大块。
- 不要复杂花纹 logo、品牌标。

## 判断标准

1. **该不该画人**：去掉圆点，图意是否仍然成立？成立 → 这张本来就不需要人，返回去把结构画得更清楚。
2. **他有没有在干活**：需要人时，去掉他图意就说不清（比如「他在卡住的机器里拉纸带」）→ 合格。
3. **他是不是过大**：全身超过图高 30% 或只剩半身 → 重画。
